Pipeline Orchestration

You say WHAT. Dispatcher decides HOW.

User→Dispatcher→Workers→Ship

Example: build a REST API

  1. 01 Classify & Route (Dispatcher)

    Menganalisis prompt user, mengidentifikasi worker yang dibutuhkan, dan menentukan model AI terbaik untuk setiap peran.

  2. 02 Define Scope (PM)

    Menerjemahkan keinginan user menjadi file spesifikasi teknis (spesifikasi fungsional, backlog, dan kriteria penerimaan).

  3. 03 System Design (Architect)

    Merancang arsitektur sistem, skema database, kontrak API, serta membuat keputusan tradeoff teknologi.

  4. 04 Parallel Implementation (Frontend & Backend)

    Mengeksekusi penulisan kode komponen UI, logika bisnis backend, integrasi API secara paralel menggunakan engine OpenCode.

  5. 05 Verification & Test (QA)

    Membuat test suite otomatis, melakukan testing visual/integrasi, serta memverifikasi kesesuaian dengan acceptance criteria.

  6. 06 Quality Gate & Approval (Governor)

    Melakukan review final dari perubahan file sebelum diserahkan kembali kepada user untuk dideploy.

Getting Started

Setup and run your first multi-agent workspace.

Prerequisites

  • Hermes Agent CLI installed
  • Node.js installed (v18+)
  • API key (OpenRouter, Anthropic, OpenAI, or custom)

Install (3 steps)

1

Install OpenCode

npm install -g opencode-ai@latest
2

Clone AIC skill

git clone https://github.com/Deriest/aic-skill.git
cp -r aic-skill/* ~/.hermes/skills/workflows/aic/
3

Load & configure

/aic

First Task

/aic
build a todo app with React and a REST API

You'll see pipeline phases, worker dispatches, and final delivery — all logged to the dashboard.
