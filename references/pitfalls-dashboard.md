## Dashboard UI & Metrics (Recharts & Next.js/Vite)

- **Recharts BarChart Dark Mode**: The default `<Tooltip />` renders a solid white background block when hovering over bars, which breaks dark mode aesthetics. Fix by adding `cursor={{ fill: 'transparent' }}` to the `<Tooltip />`.
- **Recharts AreaChart Single Data Point**: If there is only one data point on the X-axis (e.g. one day of data), `AreaChart` cannot draw the filled area (it will just render dots). If your data is discrete (like list of workers) or often single-point, use `BarChart` instead.
- **Cache Hit Rate Formula**: The correct formula for token cache hit rate is `cache / (cache + input)`, NOT `cache / (input + output)`. Output tokens are generated, not read from cache.
- **Next.js vs Vite React SPA**: If planning an architecture for an existing dashboard, verify if it's Next.js or Vite React SPA first. Do not assume Next.js API routes (`app/api/route.ts`) if the server is a custom Node.js Express/HTTP server serving a Vite SPA.
- **Git Auto-Commit Guard**: The Governor worker and Dispatcher (you) must NEVER automatically `git commit` or `git merge`. Always stop and ask the user to explicitly choose the action (commit to main, new branch, or merge).
- **spawn-worker.sh JSON Escaping**: When editing curl POST calls in spawn-worker.sh, ALWAYS escape JSON quotes with `\\\"` inside double-quoted strings. `{"agent":"$WORKER"}` is WRONG — it silently fails because bash breaks the string at the first unescaped quote. Correct: `{\\\"agent\\\":\\\"$WORKER\\\",\\\"status\\\":\\\"complete\\\"}`. The `|| true` at the end swallows the error, making this extremely hard to debug. **Proven bug (2026-07-08):** worker status stuck at "working" because complete call had unescaped quotes. User: "pipeline tidak terupdate saat pengetestan, worker juga cuma dispatch yang update".
- **Vite manualChunks Circular Dependency**: `manualChunks: { ui: ['recharts'] }` separate from `vendor: ['react']` creates a circular chunk that causes blank page in production build. Dev mode works fine (Vite serves files individually). Fix: merge recharts into vendor chunk: `vendor: ['react', 'react-dom', 'framer-motion', 'recharts']`.
- **Pre-populate all workers in chart data**: Always include all 9 workers (excluding dispatcher) with 0 values to reserve X-axis space. Use SHORT_NAMES (Aria, Atlas, etc.) for chart labels, WORKER_NAMES (Aria (PM), Atlas (Architect), etc.) for table display.
- **Worker display name hierarchy**: Chart X-axis = SHORT_NAMES (short, fits 9 bars). Tooltip + Table = WORKER_NAMES (full name + jobdesc). Dispatcher excluded from all tracking (not spawned via opencode run).
